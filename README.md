# Void Arena

Браузерный космический бой в духе NetWars (Novell, 1993): векторная 3D-арена, вид из кабины, корабли с лазерами и самонаводящимися ракетами. Свободный ремейк: собственное название, модели и звуки, без ассетов оригинала.

## Запуск

```bash
npm install
npm run dev        # dev-сервер, доступен по локальной сети (--host)
npm run build      # проверка типов + production-сборка в dist/
npm run preview    # просмотр собранной версии
npm test           # юнит-тесты (математика, модели, симуляция, прокачка)
```

Чтобы проверить тач и гироскоп на телефоне, откройте адрес из вывода `npm run dev` в браузере телефона (устройства должны быть в одной сети). Гироскоп на iOS требует HTTPS: для проверки используйте туннель или локальный сертификат.

## Режимы

- **Дезматч**: каждый сам за себя, до 12 убийств.
- **Командный бой**: две команды с базами (возрождение и ремонт у своей базы), до 20 убийств.
- **Волны ботов**: нарастающие волны, каждая третья с тяжёлым кораблём, 3 жизни.

За бои начисляются кредиты; в ангаре можно улучшать корпус, лазеры, энергию, двигатель, ракеты и манёвренность (до 5 уровней). Прогресс хранится в `localStorage`.

## Управление

| Источник | Действия |
|---|---|
| Клавиатура | WASD/стрелки: курс, Q/E: крен, R/F: тяга, Пробел: огонь, M/Enter: ракета (нужен захват цели), V: вид снаружи, Tab: таблица, P/Esc: пауза, I: инверсия, G: центрировать гироскоп |
| Мышь | Клик по игре захватывает мышь; движение: курс, ЛКМ: огонь, ПКМ: ракета, колесо: тяга |
| Сенсор | Касание слева: плавающий стик, ОГОНЬ и РАКЕТА справа, ползунок тяги, кнопки ВИД, ЦЕНТР (гироскоп), пауза |
| Геймпад | Левый стик: курс, правый: крен и тяга, RT/A: огонь, RB/B/X/LT: ракета, Y: вид, Start: пауза, Select: центр гироскопа |
| Гироскоп | Включается в настройках; наклон телефона добавляется к стику |

## Устройство

- `src/engine/`: векторная математика и кватернионы, модели, рендер на Canvas 2D (проекция, отсечение по ближней плоскости, сортировка граней, заливка полигонов с освещением и туманом).
- `src/game/`: симуляция с фиксированным шагом 60 Гц. Игрок и боты управляют кораблями через один и тот же `ShipInput`, а события наружу идут через `SimEvent`: это задел под сетевой режим (WebSocket-сервер поверх существующей симуляции).
- `src/input/`: клавиатура, мышь, тач, геймпад, гироскоп.
- `src/ui/`: сцена, HUD с радаром, частицы, меню, перевод RU/EN.
- `src/audio/`: звуки синтезируются через Web Audio.
- `tests/`: юнит-тесты.
