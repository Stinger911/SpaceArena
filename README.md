# Space Arena

Браузерный космический бой в духе NetWars (Novell, 1993): векторная 3D-арена, вид из кабины, корабли с лазерами и самонаводящимися ракетами. Свободный ремейк: собственное название, модели и звуки, без ассетов оригинала.

## Запуск

```bash
npm install
npm run dev        # dev-сервер, доступен по локальной сети (--host)
npm run build      # проверка типов + production-сборка в dist/
npm run preview    # просмотр собранной версии
npm test           # юнит-тесты (математика, модели, симуляция, прокачка)
```

Чтобы проверить тач и гироскоп на телефоне, откройте адрес из вывода `npm run dev` в браузере телефона (устройства должны быть в одной сети). Гироскоп на iOS требует HTTPS: для проверки используйте туннель или локальный сертификат.

## Режимы

- **Дезматч**: каждый сам за себя, до 12 убийств.
- **Командный бой**: две команды с базами (возрождение и ремонт у своей базы), до 20 убийств.
- **Волны ботов**: нарастающие волны, каждая третья с тяжёлым кораблём, 3 жизни.

За бои начисляются кредиты; в ангаре можно улучшать корпус, лазеры, энергию, двигатель, ракеты и манёвренность (до 5 уровней). Прогресс хранится в `localStorage`.

## Управление

| Источник | Действия |
|---|---|
| Клавиатура | WASD/стрелки: курс, Q/E: крен, R/F: тяга, Пробел: огонь, M/Enter: ракета (нужен захват цели), V: вид снаружи, Tab: таблица, P/Esc: пауза, I: инверсия, G: центрировать гироскоп |
| Мышь | Клик по игре захватывает мышь; движение: курс, ЛКМ: огонь, ПКМ: ракета, колесо: тяга |
| Сенсор | Касание слева: плавающий стик, ОГОНЬ и РАКЕТА справа, ползунок тяги, кнопки ВИД, ЦЕНТР (гироскоп), пауза |
| Геймпад | Левый стик: курс, правый: крен и тяга, RT/A: огонь, RB/B/X/LT: ракета, Y: вид, Start: пауза, Select: центр гироскопа |
| Гироскоп | Включается в настройках; наклон телефона добавляется к стику |

## Устройство

- `src/engine/`: векторная математика и кватернионы, модели, рендер на Canvas 2D (проекция, отсечение по ближней плоскости, сортировка граней, заливка полигонов с освещением и туманом).
- `src/game/`: симуляция с фиксированным шагом 60 Гц. Игрок(и) и боты управляют кораблями через один и тот же `ShipInput`, события наружу идут через `SimEvent`.
- `src/net/`: мультиплеер поверх реле Cardputer (см. ниже).
- `server/`: Node.js-эмулятор платформы Cardputer для отладки.
- `src/input/`: клавиатура, мышь, тач, геймпад, гироскоп.
- `src/ui/`: сцена, HUD с радаром, частицы, меню, перевод RU/EN.
- `src/audio/`: звуки синтезируются через Web Audio.
- `tests/`: юнит-тесты.

## Мультиплеер (платформа CardPutter Games)

Игра работает как сетевая игра платформы [CardPuterGames](https://github.com/Stinger911/CardPuterGames): ESP32 Cardputer поднимает Wi-Fi, портал с лобби и **WebSocket-реле** (JSON до 1 КБ всем остальным в комнате). Реле ничего не считает, поэтому бой ведёт **браузер хоста** (владельца комнаты):

- клиент шлёт хосту ввод (~15 пакетов/с, ≈50 байт);
- хост рассылает снимки кораблей (~15/с, нарезка по ≤ 900 байт), события (выстрелы, попадания, убийства) и статистику;
- свой корабль клиент предсказывает локально и подтягивает к состоянию хоста, чужие интерполирует (≈140 мс задержки показа);
- вышедший игрок заменяется ботом, уход хоста завершает бой;
- лобби, список комнат и старт даёт портал Cardputer, у игры своего лобби нет. До 4 игроков (`manifest.json`), остальные места занимают боты.

Трафик хоста: ≈ 5–8 КБ/с исходящего (клиент ≈ 0,8 КБ/с); размеры и частоты настраиваются в `NET` (`src/net/protocol.ts`).

### Отладка без железа

```bash
npm run mp          # сборка для SD + эмулятор Cardputer на http://localhost:8080
npm run mp:lag      # то же с задержкой 60±25 мс
```

Откройте `http://localhost:8080/` в двух окнах (или на телефоне по IP компьютера): гость → «Найти игроков» → создать комнату / войти → хост жмёт «Старт» → хост выбирает режим и жмёт «В БОЙ». Эмулятор повторяет API лобби, `/sdk.js`, реле, лимиты прошивки (24 сессии, 8 комнат, 1 КБ на сообщение, 20 с на переход портал → игра) и подстановку `.gz`; флаги `--latency/--jitter/--loss/--stats`, счётчики на `/api/debug`. `?debug` или F3 в игре показывает поток данных.

```bash
npm run e2e         # два реальных браузера (Playwright) играют через эмулятор
```

### Установка на Cardputer

`npm run build:cardputer` собирает `dist-cardputer/games/space-arena/` (около 32 КБ: `index.html`, `app.js.gz`, `manifest.json`). Скопируйте папку `space-arena` в `/games/` на SD-карту.
